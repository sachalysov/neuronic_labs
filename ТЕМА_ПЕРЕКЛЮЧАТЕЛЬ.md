## 2️⃣ Компонент переключателя темы

### Файл: `src/components/theme-toggle.tsx`

React-компонент для переключения темы:

```tsx
"use client"

import { useEffect, useState } from "react"
import { Moon, Sun } from "lucide-react"

export function ThemeToggle() {
  const [theme, setTheme] = useState<"light" | "dark">("light")
  const [mounted, setMounted] = useState(false)

  // Инициализация темы при загрузке
  useEffect(() => {
    // Читаем сохраненную тему из localStorage
    const savedTheme = localStorage.getItem("theme") as "light" | "dark" | null
    
    // Если нет сохраненной темы, проверяем системные предпочтения
    const prefersDark = window.matchMedia("(prefers-color-scheme: dark)").matches
    
    // Определяем начальную тему
    const initialTheme = savedTheme || (prefersDark ? "dark" : "light")
    
    // Применяем тему
    if (initialTheme === "dark") {
      document.documentElement.dataset.theme = "dark"
    } else {
      delete document.documentElement.dataset.theme
    }
    
    setTheme(initialTheme)
    setMounted(true)
  }, [])

  // Переключение темы
  const toggleTheme = () => {
    const newTheme = theme === "dark" ? "light" : "dark"
    
    // Применяем тему к HTML
    if (newTheme === "dark") {
      document.documentElement.dataset.theme = "dark"
    } else {
      delete document.documentElement.dataset.theme
    }
    
    // Сохраняем в localStorage
    localStorage.setItem("theme", newTheme)
    
    // Обновляем state
    setTheme(newTheme)
  }

  return (
    <button
      onClick={toggleTheme}
      className="flex items-center gap-2 px-4 py-2 rounded-lg bg-card/50 hover:bg-card border border-border/50 hover:border-primary/50 text-foreground transition-all duration-250 hover:shadow-md"
      aria-label="Переключить тему сайта"
      aria-pressed={theme === "dark"}
    >
      {theme === "dark" ? (
        <>
          <Sun className="w-5 h-5 text-primary" />
          <span className="text-sm font-medium hidden sm:inline">Светлая тема</span>
        </>
      ) : (
        <>
          <Moon className="w-5 h-5 text-primary" />
          <span className="text-sm font-medium hidden sm:inline">Тёмная тема</span>
        </>
      )}
    </button>
  )
}
```

### Логика работы:

1. **При загрузке страницы:**
   - Проверяет `localStorage.getItem('theme')`
   - Если нет сохраненной темы → проверяет `window.matchMedia('(prefers-color-scheme: dark)')`
   - Применяет тему до рендеринга React

2. **При клике:**
   - Переключает атрибут `data-theme="dark"` на `<html>`
   - Сохраняет выбор в `localStorage`
   - Обновляет иконку и текст кнопки

3. **Иконки и текст:**
   - **Тёмная тема активна:** иконка ☀️ Sun + текст "Светлая тема" (показывает, что переключится на светлую)
   - **Светлая тема активна:** иконка 🌙 Moon + текст "Тёмная тема" (показывает, что переключится на тёмную)

## 4️⃣ Предотвращение мигания темы

### Файл: `index.html`

Инлайн-скрипт в `<head>` применяет тему ДО загрузки React:

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>NEUROMODUL - Автоматизация бизнеса с помощью ИИ</title>
    
    <!-- Скрипт инициализации темы для предотвращения мигания -->
    <script>
      (function() {
        try {
          var savedTheme = localStorage.getItem('theme');
          var prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
          var theme = savedTheme || (prefersDark ? 'dark' : 'light');
          
          if (theme === 'dark') {
            document.documentElement.setAttribute('data-theme', 'dark');
          }
        } catch (e) {}
      })();
    </script>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>
```

**Зачем это нужно:**
- Скрипт выполняется синхронно ДО рендеринга страницы
- Предотвращает "вспышку" неправильной темы при загрузке
- Пользователь сразу видит нужную тему

## 🚀 Как протестировать

1. **Первая загрузка страницы:**
   - Откройте сайт в приватном окне
   - Должна загрузиться светлая тема (или тёмная, если в системе dark mode)
   - Не должно быть мигания

2. **Переключение темы:**
   - Нажмите на кнопку переключения в шапке
   - Тема должна плавно измениться (0.25s)
   - Перезагрузите страницу — тема должна сохраниться

3. **Системные предпочтения:**
   - Очистите localStorage: `localStorage.removeItem('theme')`
   - Измените тему в настройках ОС (Settings → Appearance → Dark)
   - Перезагрузите страницу — должна применится системная тема

4. **Проверка контраста:**
   - Убедитесь, что весь текст читаем в обеих темах
   - Особенно важно: красные кнопки, приглушенный текст, границы карточек
