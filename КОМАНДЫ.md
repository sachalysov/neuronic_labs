# 🚀 Команды для запуска проекта

## 1. Установка зависимостей (первый раз)

```bash
npm install
```

## 2. Разработка (dev сервер)

```bash
npm run dev
```

**Откроется:** http://localhost:5173

## 3. Production сборка

```bash
npm run build
```

**Результат:** папка `dist/` с готовым HTML/JS/CSS

## 4. Проверка production сборки

```bash
npm run preview
```

## 5. Настройка webhook для чата (опционально)

Создайте файл `.env`:

```env
VITE_CHAT_WEBHOOK_URL=https://ваш-webhook-url.com/api/chat
```

## 📁 Структура проекта

```
├── index.html          # HTML шаблон
├── vite.config.ts      # Конфиг Vite
├── tsconfig.json       # Конфиг TypeScript
├── package.json        # Зависимости
├── src/
│   ├── main.tsx        # Entry point
│   ├── App.tsx         # Root компонент
│   ├── globals.css     # Глобальные стили
│   ├── components/     # React компоненты
│   ├── pages/          # Страницы
│   ├── services/       # API сервисы
│   └── lib/           # Утилиты
└── public/            # Статические файлы (картинки)
```

## 🎯 Быстрый старт

1. **Установить зависимости:**
   ```bash
   npm install
   ```

2. **Запустить dev сервер:**
   ```bash
   npm run dev
   ```

3. **Открыть в браузере:**
   http://localhost:5173

4. **Собрать для production:**
   ```bash
   npm run build
   ```

5. **Задеплоить:**
   - Загрузить папку `dist/` на любой статический хостинг
   - Или использовать Vercel/Netlify
