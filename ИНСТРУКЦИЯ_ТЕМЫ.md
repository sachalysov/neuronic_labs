# 🎨 Быстрый старт: Переключатель тем

## Что добавлено

✅ Полноценная система переключения между светлой и тёмной темами  
✅ Кнопка переключения в шапке сайта  
✅ Фирменный красный цвет NEURONIC LABS для светлой темы  
✅ Сохранение выбора пользователя в localStorage  
✅ Плавная анимация переключения (0.25s)

## Как запустить

```bash
# Установите зависимости (если ещё не установлены)
npm install

# Запустите dev-сервер
npm run dev
```

Откройте браузер по адресу `http://localhost:5173`

## Как использовать

### 1. Переключение темы
- В правом верхнем углу шапки найдите кнопку с иконкой луны/солнца
- Кликните на неё для переключения темы
- Ваш выбор автоматически сохранится

### 2. Что показывает кнопка
- **Иконка луны 🌙 + текст "Тёмная тема"** = сейчас активна светлая тема, кликните чтобы включить тёмную
- **Иконка солнца ☀️ + текст "Светлая тема"** = сейчас активна тёмная тема, кликните чтобы включить светлую

### 3. Системные предпочтения
При первом посещении сайт автоматически определит вашу системную тему (Settings → Appearance) и применит её.

## Технические детали

### Структура файлов
```
src/
├── components/
│   ├── theme-toggle.tsx          ← Компонент кнопки переключения
│   └── sticky-header.tsx         ← Обновлена шапка (добавлена кнопка)
├── pages/
│   └── HomePage.tsx              ← Адаптированы градиенты hero-секции
├── globals.css                   ← CSS-переменные для обеих тем
└── lib/
    └── theme-init.ts             ← Утилита инициализации темы

index.html                        ← Скрипт предотвращения мигания
```

### CSS-переменные

Все цвета определены через CSS-переменные в `src/globals.css`:

**Светлая тема (`:root`):**
```css
--background: oklch(1 0 0);           /* Белый */
--foreground: oklch(0.12 0 0);        /* Темный текст */
--primary: oklch(0.50 0.24 25);       /* Красный NEURONIC LABS */
--card: oklch(0.98 0 0);              /* Светло-серые карточки */
--border: oklch(0.90 0 0);            /* Светлые границы */
```

**Тёмная тема (`html[data-theme="dark"]`):**
```css
--background: oklch(0.08 0 0);        /* Чёрный */
--foreground: oklch(0.98 0 0);        /* Белый текст */
--primary: oklch(0.55 0.22 27);       /* Яркий красный */
--card: oklch(0.12 0 0);              /* Тёмные карточки */
--border: oklch(0.22 0 0);            /* Тёмные границы */
```

### Как работает переключение

1. При клике на кнопку устанавливается/удаляется атрибут `data-theme="dark"` на элементе `<html>`
2. CSS автоматически применяет соответствующие переменные
3. Выбор сохраняется в `localStorage.setItem('theme', 'light' | 'dark')`
4. При следующей загрузке страницы тема восстанавливается

## Кастомизация цветов

### Изменить фирменный красный цвет

Откройте `src/globals.css` и найдите:

```css
:root {
  --primary: oklch(0.50 0.24 25); /* ← Измените здесь для светлой темы */
}

html[data-theme="dark"] {
  --primary: oklch(0.55 0.22 27); /* ← Измените здесь для тёмной темы */
}
```

### Добавить дополнительные цвета

Можете добавить свои переменные в обе темы:

```css
:root {
  --custom-accent: oklch(0.60 0.15 200); /* Ваш цвет для светлой темы */
}

html[data-theme="dark"] {
  --custom-accent: oklch(0.70 0.12 200); /* Ваш цвет для тёмной темы */
}
```

Затем используйте в Tailwind:

```tsx
<div className="bg-[var(--custom-accent)]">...</div>
```

## Проблемы и решения

### ❌ Тема мигает при загрузке
**Решение:** Убедитесь, что скрипт в `index.html` выполняется ДО загрузки React:
```html
<head>
  <!-- ... -->
  <script>
    (function() {
      var theme = localStorage.getItem('theme') || 'light';
      if (theme === 'dark') {
        document.documentElement.setAttribute('data-theme', 'dark');
      }
    })();
  </script>
</head>
```

### ❌ Кнопка не меняет текст/иконку
**Решение:** Проверьте консоль браузера на ошибки. Компонент должен правильно обновлять state.

### ❌ Некоторые элементы не меняют цвет
**Решение:** Убедитесь, что в компонентах используются CSS-переменные через Tailwind-классы:
```tsx
// ❌ Хардкод
<div className="bg-black text-white">

// ✅ Через переменные
<div className="bg-background text-foreground">
```

### ❌ Цвета не соответствуют дизайну
**Решение:** Откройте `src/globals.css` и настройте значения OKLCH-цветов под ваш бренд.
