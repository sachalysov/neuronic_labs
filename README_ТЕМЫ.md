# 🎨 Система переключения тем - NEURONIC LABS

> Полноценная система переключения между светлой и тёмной темами для лендинга агентства по внедрению ИИ

---

## 🚀 Быстрый старт

```bash
# Запустить сайт
npm run dev
```

Откройте браузер → найдите кнопку с иконкой 🌙/☀️ в шапке → кликните для переключения темы.

## 💡 Как работает

```
Пользователь кликает кнопку
         ↓
JavaScript меняет атрибут data-theme на <html>
         ↓
CSS автоматически применяет переменные для новой темы
         ↓
Плавная анимация за 0.25 секунды
         ↓
Выбор сохраняется в localStorage
```
