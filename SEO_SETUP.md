# Настройка SEO с Pre-rendering

## Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

Это установит:
- `puppeteer` - для pre-rendering
- `tsx` - для запуска TypeScript скриптов
- `express` - для сервера с поддержкой ботов

### 2. Сборка с pre-rendering

```bash
npm run build:prerender
```

Этот скрипт:
1. Компилирует TypeScript
2. Собирает проект через Vite
3. Запускает preview сервер
4. Рендерит все страницы через Puppeteer
5. Сохраняет HTML файлы в `dist/`

### 3. Проверка результата

```bash
npm run check:prerender
```

Проверяет, что все pre-rendered файлы созданы и содержат необходимые мета-теги.

## Использование в Production

### Вариант 1: Node.js сервер (рекомендуется)

```bash
node server.js
```

Сервер автоматически определяет поисковых ботов и отдает им pre-rendered HTML.

### Вариант 2: Apache (.htaccess)

Файл `.htaccess` уже настроен в `public/.htaccess`. Просто скопируйте его в корень сайта.

### Вариант 3: Nginx

Используйте конфигурацию из `nginx.conf.example`. Обновите пути и настройки под ваш сервер.

## Troubleshooting

### Pre-rendering не запускается

1. Убедитесь, что порт 4173 свободен
2. Проверьте, что проект собран: `npm run build`
3. Проверьте логи на наличие ошибок

### Мета-теги не сохраняются

1. Убедитесь, что страница использует `useMeta` hook
2. Увеличьте время ожидания в `scripts/prerender.mjs`

### Сервер не определяет ботов

1. Проверьте user-agent в запросе
2. Убедитесь, что сервер запущен
3. Проверьте конфигурацию веб-сервера
