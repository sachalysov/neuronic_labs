# Реализация соответствия 152-ФЗ

## Обзор изменений

Реализована функциональность для соответствия Федеральному закону № 152-ФЗ «О персональных данных».

## Измененные файлы

### Новые файлы

1. **`src/lib/consent.ts`**
   - Утилиты для управления согласием
   - Хранение в `localStorage` с ключом `pdn-consent`
   - Значения: `accepted`, `declined`, `null`

2. **`src/components/consent-gate.tsx`**
   - Компонент-шлюз для блокировки доступа до получения согласия
   - Показывает модальное окно при первом посещении
   - Блокирует доступ при отклонении согласия
   - Инициализирует Яндекс.Метрику только после согласия

3. **`src/pages/PrivacyPolicyPage.tsx`**
   - Страница политики конфиденциальности
   - Маршрут: `/politika-konfidentsialnosti`
   - Содержит всю необходимую информацию согласно 152-ФЗ

4. **`src/pages/ConsentRequiredPage.tsx`**
   - Страница для пользователей, отклонивших согласие
   - Маршрут: `/consent-required`
   - Позволяет принять согласие позже

5. **`src/components/ui/checkbox.tsx`**
   - Компонент чекбокса на основе Radix UI
   - Используется в формах для получения согласия

### Измененные файлы

1. **`src/main.tsx`**
   - Удалена автоматическая инициализация Яндекс.Метрики
   - Инициализация перенесена в `ConsentGate` (только после согласия)

2. **`src/App.tsx`**
   - Добавлен `ConsentGate` для оборачивания всех роутов
   - Добавлены роуты для страницы политики и страницы требования согласия
   - Админ-страницы доступны без согласия

3. **`src/lib/meta.ts`**
   - Добавлена функция `createPrivacyPolicyMetaTags()` для SEO

4. **`src/components/consultation-modal.tsx`**
   - Добавлен обязательный чекбокс согласия на обработку персональных данных
   - Валидация чекбокса перед отправкой формы
   - Ссылка на политику конфиденциальности

5. **`src/pages/HomePage.tsx`**
   - Добавлен обязательный чекбокс согласия в форму обратной связи
   - Валидация чекбокса перед отправкой формы
   - Ссылка на политику конфиденциальности

## Функциональность

### 1. Хранение согласия
- Ключ: `pdn-consent` в `localStorage`
- Значения: `accepted`, `declined`, `null` (отсутствует)

### 2. Блокировка доступа
- При первом посещении показывается модальное окно согласия
- При отклонении согласия пользователь перенаправляется на `/consent-required`
- Доступ к сайту блокируется до получения согласия

### 3. Инициализация сторонних сервисов
- Яндекс.Метрика инициализируется только после получения согласия
- Функция `setupYandexMetrika()` вызывается в `ConsentGate` при принятии согласия

### 4. Формы
- Все формы сбора персональных данных содержат обязательный чекбокс согласия
- Чекбокс валидируется перед отправкой формы
- Ссылка на политику конфиденциальности в каждой форме

### 5. Публичные страницы
- `/politika-konfidentsialnosti` - доступна без согласия
- `/consent-required` - доступна без согласия
- `/admin/*` - админ-страницы доступны без согласия

## Проверка

### Чек-лист для тестирования

1. **Чистая сессия (инкогнито)**
   - [ ] При первом посещении показывается модальное окно согласия
   - [ ] Яндекс.Метрика не загружается до принятия согласия
   - [ ] Чат-виджет не доступен до принятия согласия

2. **После принятия согласия**
   - [ ] Яндекс.Метрика инициализируется
   - [ ] Сайт полностью доступен
   - [ ] Согласие сохраняется в `localStorage`

3. **После отклонения согласия**
   - [ ] Пользователь перенаправляется на `/consent-required`
   - [ ] Доступ к основному контенту заблокирован
   - [ ] Можно принять согласие позже

4. **Формы**
   - [ ] Чекбокс согласия обязателен для отправки
   - [ ] Ссылка на политику конфиденциальности работает
   - [ ] Валидация работает корректно

5. **Очистка localStorage**
   - [ ] После очистки `pdn-consent` модальное окно появляется снова

- Стилизация не изменялась, добавлена только функциональность
- Все изменения соответствуют требованиям 152-ФЗ
- Яндекс.Метрика (счетчик: 106099175) инициализируется только после согласия
- Чат-виджеты и формы блокируются до получения согласия
