## 🔧 Настройка webhook для чата (опционально)

Если хотите подключить реальный чат:

1. Создайте файл **`.env`** в корне проекта:

```env
VITE_CHAT_WEBHOOK_URL=https://ваш-webhook.com/api/chat
```

2. Перезапустите dev сервер

Без `.env` файла чат будет работать с **mock ответами** - это нормально для разработки! ✅

## 📤 Деплой на production

### Вариант 1: Vercel (рекомендуется)

```bash
npm run build
vercel --prod
```

### Вариант 2: Netlify

1. Соберите проект: `npm run build`
2. Перетащите папку `dist/` на https://app.netlify.com/drop

### Вариант 3: GitHub Pages

1. Соберите: `npm run build`
2. Push папку `dist/` в `gh-pages` branch

### Вариант 4: Любой хостинг

Загрузите содержимое папки `dist/` через FTP/SFTP на ваш хостинг.

## 📊 Преимущества Vite vs Next.js

| Параметр | Next.js | Vite |
|----------|---------|------|
| **Dev старт** | 5-10s | 1-2s ⚡ |
| **HMR** | 1-2s | 50ms ⚡⚡⚡ |
| **Build** | 40s | 15s ⚡⚡ |
| **Размер** | ~500KB | ~300KB 📦 |
| **Деплой** | Серверный | Статический 🎉 |
| **Хостинг** | Дорого | Бесплатно! 💰 |

## 🐛 Если что-то не работает

### Ошибка импортов
```bash
# Переустановите зависимости
rm -rf node_modules package-lock.json
npm install
```

### Tailwind не работает
Проверьте что в `src/main.tsx` есть:
```typescript
import './globals.css'
```

### Чат не работает
Это нормально без webhook! Он работает с mock ответами.
Для реального webhook добавьте `.env` файл.
