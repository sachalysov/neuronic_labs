## CSS-переменные: как работает магия

```css
/* Светлая тема */
:root {
  --background: oklch(1 0 0);      /* Белый */
  --primary: oklch(0.50 0.24 25);  /* Красный */
}

/* Тёмная тема */
html[data-theme="dark"] {
  --background: oklch(0.08 0 0);   /* Черный */
  --primary: oklch(0.55 0.22 27);  /* Яркий красный */
}
```

### Применение в компонентах:
```tsx
// Tailwind автоматически использует CSS-переменные
<div className="bg-background text-foreground">
  <button className="bg-primary">Кнопка</button>
</div>

// Компилируется в:
// bg-background    → background-color: var(--background)
// text-foreground  → color: var(--foreground)
// bg-primary       → background-color: var(--primary)
```

## Производительность

### Что происходит при переключении:

1. **JavaScript (< 1ms):**
   - Изменяет атрибут `data-theme`
   - Записывает в `localStorage`
   - Обновляет React state

2. **Browser Reflow (< 5ms):**
   - Пересчитывает CSS-переменные
   - Применяет новые стили

3. **CSS Transitions (250ms):**
   - Плавная анимация цветов
   - GPU-ускоренная
   - Не блокирует UI

**Итого:** Мгновенная реакция + плавная визуализация

## Ключевые моменты

✅ **Минималистичный подход:** Изменяется только один атрибут `data-theme`  
✅ **Производительность:** CSS-переменные пересчитываются мгновенно  
✅ **Maintainability:** Все цвета в одном месте (`src/globals.css`)  
✅ **Extensibility:** Легко добавить новые цвета или темы  
✅ **Accessibility:** Полная поддержка клавиатуры и screen readers  
✅ **UX:** Плавные transitions, сохранение выбора, системные предпочтения
