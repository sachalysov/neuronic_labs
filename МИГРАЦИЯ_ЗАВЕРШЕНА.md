## 🚀 Как запустить:

### Установка зависимостей (если еще не установлены)

```bash
npm install
```

### Разработка

```bash
npm run dev
```

Откроется http://localhost:5173

### Production сборка

```bash
npm run build
```

Результат в папке `dist/`

### Предпросмотр production

```bash
npm run preview
```

## 🔧 Настройка webhook для чата:

Создайте файл `.env` в корне проекта:

```env
VITE_CHAT_WEBHOOK_URL=https://your-webhook-url.com/api/chat
```

Без webhook чат будет работать с mock-ответами.

## 📤 Деплой:

После `npm run build` папка `dist/` готова для любого статического хостинга:

- **Vercel**: `vercel --prod`
- **Netlify**: Drag & Drop `dist/` folder
- **GitHub Pages**: Push `dist/` к gh-pages branch
- **Любой хостинг**: Загрузите `dist/` через FTP/SFTP

## 📊 Сравнение до/после:

| Параметр          | Next.js (до)            | Vite (после)              |
| ----------------- | ----------------------- | ------------------------- |
| **Размер сборки** | ~500KB+                 | ~300KB                    |
| **Время сборки**  | ~30-60s                 | ~10-20s                   |
| **Dev сервер**    | Медленный               | Мгновенный HMR            |
| **Деплой**        | Нужен серверный рантайм | Чистый статический HTML   |
| **Хостинг**       | Vercel, Netlify и т.д.  | Любой статический хостинг |

## ✨ Преимущества миграции:

1. **Быстрее разработка** - Vite использует ES modules для мгновенного HMR
2. **Быстрее сборка** - В 2-3 раза быстрее production build
3. **Проще деплой** - Чистый статический HTML без серверного рантайма
4. **Дешевле хостинг** - Можно использовать бесплатные статические хостинги
5. **Легче код** - Нет магии Next.js, только чистый React

## 🐛 Возможные проблемы:

### Ошибка импортов

Если увидите ошибки импортов, проверьте что:

- Все пути используют `@/` alias
- Нет импортов из `next/*`

### Стили не работают

Убедитесь что:

- `src/globals.css` импортируется в `src/main.tsx`
- Tailwind CSS установлен: `npm install -D tailwindcss@^4.1.9`

### Чат не работает

- Проверьте `.env` файл
- Без webhook используются mock-ответы (это нормально для разработки)
