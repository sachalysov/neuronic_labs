## 🎯 Ключевые изменения

### 1. Server Action → Client Fetch

**Было (Next.js):**

```typescript
// app/actions/chat.ts
"use server"

export async function sendChatMessage(messageText: string): Promise<string> {
  const webhookUrl = process.env.NEXT_PUBLIC_CHAT_WEBHOOK_URL
  const response = await fetch(webhookUrl, { ... })
  return data.response
}
```

**Стало (Vite):**

```typescript
// src/services/chat.ts
export async function sendChatMessage(messageText: string): Promise<{ message: string }> {
  const webhookUrl = import.meta.env.VITE_CHAT_WEBHOOK_URL

  if (!webhookUrl) {
    // Mock для разработки
    return { message: "Mock ответ..." }
  }

  const response = await fetch(webhookUrl, { ... })
  return { message: data.response || data.message || "Извините..." }
}
```

### 2. Переменные окружения

**Было:**

```env
NEXT_PUBLIC_CHAT_WEBHOOK_URL=https://...
```

**Стало:**

```env
VITE_CHAT_WEBHOOK_URL=https://...
```
